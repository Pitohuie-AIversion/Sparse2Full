\section{研究背景}

\subsection{稀疏观测下的时空场重建需求}

在计算物理、环境监测与工程诊断等任务中，目标对象通常是定义在空间域
\(\Omega \subset \mathbb{R}^2\)（可扩展到 \(\mathbb{R}^3\)）与时间区间 \([0,T]\) 上的连续物理场
\(u(\mathbf{x},t)\)，例如速度场、压力场、温湿度场或浓度场。受限于传感器布设密度、采样带宽、测点维护与安全成本，真实系统往往只能获得有限测点、有限时间步且噪声与缺失并存的观测序列，从而形成“稀疏—噪声—不齐”的典型数据形态。

在该类条件下，上游观测不足会直接影响下游的预测、控制与诊断：预测依赖完整状态估计，控制依赖一致且可复用的观测口径，诊断依赖对异常结构（边界层、涡结构、锋面、热斑等）的稳定识别。由此产生的核心技术问题可概括为：在观测极稀疏且存在噪声与缺失的情况下，如何在连续时空域内恢复出高分辨率、可解释且与真实观测口径一致的物理场。

\subsection{科学机器学习与算子学习的推动作用}

近年来，面向偏微分方程（PDE）体系的学习方法快速发展：
\begin{itemize}
  \item 物理约束学习以 PINN 为代表，将 PDE 残差与初边界条件并入训练目标，从而在数据不足时维持物理一致性框架 \parencite{raissi2019pinn}。
  \item 算子学习以 FNO、DeepONet 等为代表，学习“函数到函数”的映射，从而支持跨初值/参数族的快速推断，并在若干任务中展现跨分辨率或零样本超分辨潜力 \parencite{li2021fno,lu2021deeponet}。
  \item 更一般的数值分析与综述工作进一步系统化了物理信息学习方法的误差机理与适用边界 \parencite{deryck2024acta_numerica}。
\end{itemize}

上述方法为稀疏观测重建提供了可行的建模工具，但工程落地仍常遭遇一个更基础的问题：训练阶段使用的退化/采样过程与评测阶段的真实观测口径不一致，导致“训练指标改善但评测口径误差不降”的断裂现象。该断裂不仅影响结论的可复现性，也会削弱模型在真实系统中的可部署性。

\section{研究动机与应用场景}

稀疏观测并非少数场景的例外，而是多数工程系统的常态。例如：
\begin{enumerate}
  \item \textbf{城市微气候与污染监测}：传感器多部署在交通枢纽、关键建筑与少量基站，空间覆盖不足且维护频率不一致；
  \item \textbf{海洋与大气观测}：遥感与浮标观测分辨率差异显著，时间戳不齐且信噪比受环境强影响；
  \item \textbf{工业过程与管网系统}：复杂几何与高温高压环境降低传感器密度与可靠性，长期数据含漂移与间断；
  \item \textbf{生物医学与材料过程成像}：采样成本与安全性约束导致观测稀疏，噪声与缺失不可避免。
\end{enumerate}

上述应用共同指向两个需求：
\begin{itemize}
  \item \textbf{高分辨率重建需求}：下游任务需要近似连续的高分辨率场；
  \item \textbf{口径一致性需求}：评测与部署依赖真实观测过程；训练阶段若未严格复用该口径，实验对比将难以审计，工程效果将难以预测。
\end{itemize}

基于此，本文将研究动机明确为：以“评测口径一致性优先”为原则，构建一套可复用、可审计、可复现的稀疏观测时空场重建框架，使数学意义的重建误差与观测意义的口径误差能够协同优化，并在统一资源约束下开展规范化对比。

\section{研究问题定义与数学形式化}

\subsection{观测模型与重建目标}

设真实高分辨率物理场为 \(u(\mathbf{x},t)\)。观测由观测算子 \(H\) 与噪声项 \(n\) 生成：
\begin{equation}
  y = H(u) + n .
  \label{eq:obs-model}
\end{equation}
其中 \(H\) 表示数据侧的采样/退化口径，覆盖下采样、裁剪、插值、边界处理与对齐策略等。重建模型 \(f_\theta\) 在给定观测 \(y\)（及可选的显式坐标编码、掩码等）后输出预测场 \(\hat{u}\)：
\begin{equation}
  \hat{u} = f_\theta(y;\theta) .
  \label{eq:recon-model}
\end{equation}

本文关注的核心目标不是单一指标最小化，而是在统一口径约束下同时降低：
\begin{itemize}
  \item \textbf{重建误差}（逼近真值的数学误差），以及
  \item \textbf{口径一致性误差}（预测经 \(H\) 作用后与观测 \(y\) 的一致性）。
\end{itemize}

\subsection{任务口径：超分辨与裁剪（示例）}

为覆盖典型的稀疏观测形态，本文将两类常见口径纳入统一形式：
\begin{itemize}
  \item \textbf{超分辨（SR）口径}：下采样前引入低通预滤以抑制混叠，再采用面积插值进行降采样。OpenCV 文档指出缩小图像时可优先使用 \texttt{INTER\_AREA} \parencite{opencv_resize}。
  \item \textbf{裁剪（Crop）口径}：在中心对齐窗口内观测；窗口大小满足网络 patch 对齐要求，并显式声明边界策略（mirror/zero/wrap）。
\end{itemize}

上述口径强调一个工程事实：当观测生成依赖具体实现细节（预滤、插值、对齐、边界），训练与评测若不共享同一实现，实验结论将难以复核。

\section{稀疏观测重建的关键挑战}

\subsection{混叠与频谱失真}

下采样会将高频能量折叠到低频，造成不可逆信息损失。工程上常采用“先低通、再缩小”的抗混叠流程。OpenCV 的滤波教程对 \texttt{GaussianBlur} 的核大小与 \(\sigma\) 参数语义给出说明，为预滤实现提供可复用依据 \parencite{opencv_gaussianblur}。在科学机器学习中，算子学习路线也讨论离散网格与表示差异导致的混叠/别名问题，并发展出“表示等价、别名无关”的设计框架，例如 ReNO \parencite{bartolucci2023reno}。

\subsection{训练口径与评测口径断裂}

训练阶段退化过程与评测阶段真实观测口径不一致时，可能出现：重建误差指标下降，但口径一致性误差不降甚至恶化。该现象会造成横向对比不公与工程不可落地。解决路径要求：
\begin{itemize}
  \item 数据侧观测算子 \(H\) 成为口径定义的唯一入口；
  \item 训练端退化算子 \(\mathrm{DC}\) 与 \(H\) 同实现、同参数、同边界与同对齐策略（镜像复用）。
\end{itemize}

\subsection{非周期边界与局部伪影扩散}

非周期边界、复杂几何与掩码缺失会诱发边界伪影、振铃与局部能量偏差，且误差可能沿时间维传播，形成“局部失真—全局退化”的链式效应。该问题不仅影响像素级误差，也会影响谱域结构与下游诊断。

\subsection{可复现性与可审计性}

训练过程受随机种子、算子实现细节、库版本与硬件差异影响。科学结论需要在统一配置与多随机种子统计下保持稳定，并提供可审计的配置快照与环境指纹。

\section{相关工作综述与定位（聚焦可落地引用）}

\subsection{物理约束学习：PINN}

PINN 将 PDE 残差与初边界条件嵌入损失函数，在数据不足时可利用物理结构作为强先验。Raissi 等在 JCP 论文系统阐述了 PINN 的基本框架与典型用法 \parencite{raissi2019pinn}。与此同时，PINN 在多尺度、高维与复杂边界条件下的优化难度也在后续研究中持续被讨论。对本文而言，PINN 的启示在于：物理一致性约束可显著影响外推与稳健性；约束实现需与真实观测口径一致，否则约束项本身也可能引入偏差。

\subsection{算子学习：FNO 与 DeepONet}

FNO 在 Fourier 空间参数化积分核，从而学习 PDE 解算子的近似 \parencite{li2021fno}。DeepONet 通过 branch/trunk 网络学习算子映射，并在 Nature Machine Intelligence 论文中从“算子通用逼近”角度进行系统论证 \parencite{lu2021deeponet}。

与本文主题直接相关的一点在于：算子学习常在不同分辨率或不同网格上训练/推断，离散表示差异与混叠会显著影响泛化；统一口径与别名无关的设计成为提升跨网格鲁棒性的关键方向 \parencite{kovachki2023neural_operator,bartolucci2023reno}。

\subsection{物理信息与算子学习的结合：Physics-informed DeepONet}

在缺乏成对输入输出监督时，引入 PDE 约束可作为有效正则；相应思路可视为将物理信息学习与算子学习进行融合。此处沿用“Physics-informed DeepONet”的常用称谓，并给出可核验检索入口：\footnote{\url{https://europepmc.org/article/pmc/pmc8480920}}
相关的误差机理与数值分析讨论可参见 Acta Numerica 综述 \parencite{deryck2024acta_numerica}。

\subsection{本文定位}

本文不将贡献限定为单一网络结构微调，而是面向工程可复现与可部署需求，系统化“评测口径一致性优先”的研究框架：
\begin{itemize}
  \item 以 \(H\) 作为口径定义的唯一入口；
  \item 以 \(\mathrm{DC}\) 对 \(H\) 镜像复用，确保训练/评测一致；
  \item 在统一统计协议下进行显著性检验与资源约束对比；
  \item 形成可审计的材料产出链路，服务论文审查与后续复现。
\end{itemize}

\section{研究内容与技术路线}

\subsection{总体路线}

本文技术路线围绕“口径统一—算法构建—严格评测—材料产出”展开：
\begin{enumerate}
  \item \textbf{口径统一}：以 \(H\) 固化观测生成流程（预滤、插值、对齐、边界），训练端 \(\mathrm{DC}\) 与之完全复用；
  \item \textbf{算法构建}：在统一模型接口下实现若干基线与改进方法，并保持输入打包（\nolinkurl{mask/coords/baseline}）一致；
  \item \textbf{严格评测}：多随机种子统计、显著性检验、资源四项透明报告；
  \item \textbf{材料产出}：配置快照、环境指纹、指标表、代表图与失败案例归档。
\end{enumerate}

\subsection{指标体系与一致性目标}

本文采用两类误差作为核心指标：
\begin{itemize}
  \item \textbf{相对重建误差（Rel-L2）}：
  \begin{equation}
    \mathrm{Rel\text{-}L2}=\frac{\lVert \hat{u}-u\rVert_2}{\lVert u\rVert_2}.
    \label{eq:rel-l2}
  \end{equation}
  \item \textbf{口径一致性误差（\(H_{\mathrm{err}}\)）}：
  \begin{equation}
    H_{\mathrm{err}}=\lVert H(\hat{u})-y\rVert_2.
    \label{eq:h-err}
  \end{equation}
\end{itemize}
二者同步下降意味着：预测在数学意义上逼近真值，并在观测意义上与真实测量口径一致。

\subsection{损失设计（示意）}

训练阶段采用由三部分构成的目标函数（以原值域计算一致性项）：
\begin{equation}
  \mathcal{L}=\mathcal{L}_{\mathrm{rec}}
  +\lambda_{\mathrm{spec}}\mathcal{L}_{\mathrm{spec}}
  +\lambda_{\mathrm{dc}}\mathcal{L}_{\mathrm{dc}}.
  \label{eq:loss}
\end{equation}
其中：
\begin{itemize}
  \item \(\mathcal{L}_{\mathrm{rec}}\)：重建损失（原值域或统一尺度域）；
  \item \(\mathcal{L}_{\mathrm{spec}}\)：低频谱一致性，用于约束大尺度结构；
  \item \(\mathcal{L}_{\mathrm{dc}}=\lVert H(\hat{u})-y\rVert_2^2\)：以真实口径约束训练过程，使模型对观测过程保持一致性。
\end{itemize}

\section{创新点与主要贡献（面向论文审查口径）}

\begin{enumerate}
  \item \textbf{提出“评测口径一致性优先”的方法论框架}：将 \(H\) 作为观测口径的唯一入口，并要求训练端 \(\mathrm{DC}\) 镜像复用 \(H\) 的实现与参数，从机制上消除训练/评测断裂。
  \item \textbf{构建兼顾重建与口径一致性的目标函数}：通过显式的口径一致性项推动 \(H_{\mathrm{err}}\) 与 \(\mathrm{Rel\text{-}L2}\) 协同改善。
  \item \textbf{形成可复现、可审计的评测协议}：多随机种子统计与显著性检验，并同步报告资源四项（参数量、计算量、显存峰值、推断延迟），提升对比结论的工程可信度。
  \item \textbf{配套材料产出与失败案例归档}：输出指标主表、显著性报告、代表案例与失败类型分析，为后续章节实验复核与讨论提供可追溯证据链。
\end{enumerate}

\section{本章小结}

本章从稀疏观测的工程现实出发，说明时空流场重建在多类应用中的共性需求与关键困难，梳理 PINN 与算子学习（FNO、DeepONet）等代表性方法的核心思想，并指出训练口径与评测口径不一致引发的可复现性与可部署性风险。围绕该风险，本文提出“评测口径一致性优先”的研究路线，并给出统一指标体系、损失设计思路与可审计的评测/材料产出框架，为后续章节的方法论、算法与实验展开奠定基础。
