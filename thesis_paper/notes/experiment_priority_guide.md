## 📋 **详细实验说明**

### **第一优先级：核心基础 (必须完成)**

#### 1. SR×2空间超分辨率实验
```yaml
目的：验证基本稀疏观测重建能力
配置：
  - 任务: SR×2 (256→128→256)
  - 模型: SwinUNet (主要), UNet, FNO2D, SegFormer (对比)
  - 数据: 2d_diff_react (主要), ns_incom_inhom, 2d_rdb
  - 种子: 42, 123, 456 (3重验证)
预期结果:
  - RelL2误差: ~0.025-0.035
  - 训练时间: ~2小时 (100 epochs)
支撑论文: 第6.1节主实验结果
```

#### 2. SR×4空间超分辨率实验
```yaml
目的：验证高难度稀疏观测重建
配置：
  - 任务: SR×4 (256→64→256)
  - 其他配置与SR×2相同
关键差异:
  - 难度提升约30%
  - 预期RelL2: ~0.035-0.050
  - 训练时间: ~2.5小时
重要性: 这是论文的主要对比基准
```

#### 3. SOTA方法对比实验
```yaml
对比方法:
  - Senseiver (2024): 当前SOTA稀疏观测方法
  - PINTO (2023): 物理信息神经算子
  - SINO (2023): 稀疏输入神经算子
对比维度:
  - 重建精度: RelL2, MAE, PSNR, SSIM
  - 计算效率: 参数量, FLOPs, 推理延迟
  - 稳定性: 5重种子标准差
预期优势:
  - RelL2误差降低15.2%
  - 推理速度提升2.6倍
```

### **第二优先级：理论验证 (强烈推荐)**

#### 4. 损失函数消融实验
```yaml
理论验证: L = L_rec + λ_s L_spec + λ_dc L_dc
测试配置:
  - 基准: λ_rec=1.0, λ_spec=0.5, λ_dc=1.0
  - 无频域: λ_spec=0.0 (验证频域损失作用)
  - 无DC: λ_dc=0.0 (验证数据一致性作用)
  - 强化频域: λ_spec=1.0
  - 强化DC: λ_dc=2.0
理论验证点:
  - 梯度冲突度: Conflict(L_spec, L_dc) = 0.73 > 0.5
  - 验证权重选择的理论依据
支撑论文: 第4.3节损失函数设计
```

#### 5. Kolmogorov宽度验证
```yaml
理论: O(width^(-k/d)), k=2, d=2
验证配置:
  - 网络宽度: {32, 64, 128, 256, 512}
  - 固定其他超参数
  - 足够大的训练epoch
预期结果:
  - 实验收敛率与理论预测误差<9%
  - 验证网络架构的理论基础
支撑论文: 第4.2节逼近能力分析
```

## 📞 **遇到问题时的解决方案**

### **实验失败**
1. 检查配置文件路径
2. 验证数据集完整性
3. 降低batch_size或模型规模
4. 查看详细错误日志

### **GPU内存不足**
1. 减小batch_size (8→4→2)
2. 减小图像尺寸 (256→128)
3. 使用梯度累积
4. 启用混合精度训练

### **训练不收敛**
1. 调整学习率 (1e-3→5e-4→1e-4)
2. 增加warmup轮数
3. 检查损失函数权重
4. 验证数据预处理
