# 学术写作规范参考

本参考文件详细说明了中文硕士学位论文的学术写作规范与原则，作为润色 Skill 的核心依据。

## 一、学术表达基本原则

1.  **正式性**
    -   避免口语化词汇（如“搞”、“弄”、“大概”、“差不多”）。
    -   使用书面语词汇（如“构建”、“实施”、“大约”、“基本”）。
    -   避免第一人称（如“我们”、“我”），建议使用“本文”、“本研究”。

2.  **客观性与准确性**
    -   避免情绪化、宣传式表述（如“非常完美”、“令人震惊”）。
    -   避免绝对化措辞（如“彻底解决”、“完全消除”），除非有严谨证明。建议使用“有效缓解”、“显著降低”。
    -   数据描述需精确，避免模糊量词（如“很多”、“很少”）。

3.  **清晰性**
    -   句子结构不宜过长，避免多层嵌套从句。
    -   指代清晰，避免连续使用模糊代词（如“其”、“该”、“这种”），必要时重复名词。
    -   逻辑连接词使用恰当（如“因此”、“然而”、“此外”）。

## 二、引用与学术诚信

1.  **引用规范**
    -   凡引用他人观点、数据、结论，必须标注引用。
    -   引用需具体到原始出处，避免“转引”。
    -   润色时应主动提示“需补引用”的位置，特别是涉及事实性陈述或前人工作总结时。

2.  **诚信原则**
    -   **严禁伪造**：不得编造数据、参考文献、实验结果或研究背景。
    -   **严禁剽窃**：不得直接复制粘贴他人成果而不加引用。
    -   **合规改写**：润色时通过“规范转述”、“原创化重述”、“结构重组”来避免抄袭，而非简单的“同义词替换”。

## 三、润色与改写策略

1.  **去口语化**
    -   将“其实就是”改为“即”、“本质上是”。
    -   将“还有”改为“此外”、“另外”。
    -   将“为了”放在句首引导目的状语。

2.  **逻辑增强**
    -   明确段落的主题句（通常在段首）。
    -   使用连接词强化因果、转折、并列关系。
    -   确保论证过程完整：提出问题 -> 分析原因 -> 提出对策 -> 预期结果。

3.  **结构压缩**
    -   删除无意义的重复（如“综上所述，总而言之”）。
    -   合并含义相近的短句。
    -   剔除与主题无关的背景铺垫。

## 四、常见问题检查清单

-   [ ] 是否存在第一人称（“我”、“我们”）？
-   [ ] 是否使用了“大约”、“可能”等模糊词但未说明依据？
-   [ ] 是否有“显然”、“毋庸置疑”等强加于人的主观判断？
-   [ ] 图表引用是否规范（如“如图1所示”而非“如下图”）？
-   [ ] 缩略语首次出现是否给出了全称？
