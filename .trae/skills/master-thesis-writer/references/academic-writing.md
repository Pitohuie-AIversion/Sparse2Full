# 学术写作规范指南

本指南旨在帮助提升论文的学术性、逻辑性和规范性。

## 0. 写作心法 (Writing Mindset)

*   **沉浸式模仿 (Imitate Style)**：阅读顶会/顶刊论文时，关注其**句式结构**和**逻辑连接**，建立学术语感。
*   **先完成再完美 (Done is Better than Perfect)**：初稿（First Draft）允许粗糙，重点是把逻辑跑通。
*   **反馈驱动 (Feedback Loop)**：利用导师、同学或 AI 工具的反馈进行多轮迭代。

## 1. 语言风格 (Language Style)

学术写作应追求**客观 (Objective)**、**精确 (Precise)**、**正式 (Formal)**。

### ✅ 推荐做法 (Do's)
*   **使用客观语气**：多用被动语态（英文）或无主句（中文），强调研究对象而非研究者。
    *   *Bad*: We calculated the accuracy...
    *   *Good*: The accuracy was calculated... / Accuracy calculation reveals...
*   **用词精准**：避免模糊词汇，使用具体数据或明确的限定词。
    *   *Bad*: The method works well.
    *   *Good*: The proposed method achieves a 5% improvement in accuracy compared to SOTA.
*   **连接词的使用**：合理使用连接词体现逻辑关系。
    *   *因果*: Consequently, Therefore, Hence
    *   *转折*: However, Conversely, In contrast
    *   *递进*: Furthermore, Moreover, Additionally

### ❌ 避免做法 (Don'ts)
*   **避免口语化表达**：
    *   避免缩写（如 *can't, don't* → *cannot, do not*）。
    *   避免情感色彩强烈的形容词（如 *amazing, terrible* → *significant, limited*）。
*   **避免第一人称滥用**：尽量少用 "I" 或 "We"（除非强调作者的主观贡献）。
*   **避免绝对化表述**：除非有数学证明，否则少用 *always, never, prove*，多用 *suggest, indicate, demonstrate, show*。

## 2. 常见中英文学术词汇替换

| 口语/普通词汇 | 学术/正式词汇 (English) | 学术表达 (中文) |
| :--- | :--- | :--- |
| big / huge | significant, substantial | 显著的，大幅的 |
| show | demonstrate, illustrate, reveal | 展示，揭示，表明 |
| change | modify, alter, transform | 修改，变换 |
| use | utilize, employ, leverage | 利用，采用 |
| help | facilitate, aid, assist | 辅助，促进 |
| fix | resolve, address, rectify | 解决，修正 |
| bad | detrimental, adverse, suboptimal | 不利的，次优的 |
| get | obtain, acquire, derive | 获取，推导 |
| make | generate, construct, synthesize | 生成，构建 |

## 3. 引用规范 (Citations)

*   **引用目的**：支撑论点、承认前人贡献、提供背景信息。
*   **避免剽窃**：凡是引用他人观点、数据、图表，必须注明出处。
*   **引用格式**：
    *   文中引用 (In-text)：(Author, Year) 或 [1]。
    *   文末参考文献 (References)：确保包含作者、标题、期刊/会议、年份、卷号页码等完整信息。
*   **交叉引用**：图、表、公式在文中必须被提及（如 "如图3所示..."）。

## 4. 图表规范 (Figures and Tables)

*   **标题 (Caption)**：图标题在下，表标题在上。
*   **自明性**：图表应尽可能包含足够信息，让读者不看正文也能大致理解。
*   **清晰度**：矢量图优先，字体大小适中，线条清晰。

## 5. 论文自查清单 (Checklist)

*   [ ] 摘要是否涵盖了背景、目的、方法、结果、结论？
*   [ ] 引言逻辑是否顺畅（背景->Gap->本文工作->贡献）？
*   [ ] 方法部分公式符号是否定义清晰且统一？
*   [ ] 实验对比是否公平？基线是否涵盖了最新SOTA？
*   [ ] 结论是否回应了引言中提出的问题？
*   [ ] 参考文献格式是否统一？
*   [ ] 是否消除了所有的拼写和语法错误？
