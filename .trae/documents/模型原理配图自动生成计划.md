# 模型原理配图自动生成计划

为满足您对 `models/spatial` 目录下所有模型生成专业技术原理配图（架构图、流程图、性能示意图）的需求，我制定了以下基于 Python (`matplotlib`) 的全自动化生成方案。此方案不依赖外部非标准库（如 graphviz 二进制），确保在当前环境中可直接运行。

## 1. 核心工具开发 (`tools/visualization/generate_model_diagrams.py`)
我们将开发一个专用的可视化工具脚本，包含以下模块：

### A. 架构图生成器 (Architecture Diagram)
- **原理**：通过反射（Introspection）遍历模型实例的 `named_children`（如 `encoder`, `decoder`, `body`, `head`）。
- **实现**：使用 `matplotlib.patches` 绘制矢量级“方框+箭头”图。
- **功能**：
  - 自动提取子模块名称作为图注。
  - 根据模块层级自动排版（垂直/水平布局）。
  - 支持 CMYK 风格配色（学术蓝/灰/红）。

### B. 算法流程图生成器 (Flowchart)
- **原理**：基于 Sparse2Full 项目的通用处理范式（Sparse Input $\rightarrow$ Coordinate Encoding $\rightarrow$ Feature Extraction $\rightarrow$ Reconstruction $\rightarrow$ Dense Output）。
- **实现**：绘制标准流程图，并标注关键数学公式（如 $y = F(x, \theta)$）。
- **定制**：根据模型类型（CNN/Transformer/FNO）微调流程节点名称。

### C. 性能对比示意图生成器 (Performance Schematic)
- **原理**：生成符合学术标准的示例数据图（因当前无全量真实训练数据）。
- **内容**：
  - **收敛曲线**：Training/Validation Loss vs Epochs。
  - **误差分布**：Rel-L2 Error 直方图或箱线图。
  - **标注**：包含 "Schematic Representation" 水印，避免误导。

## 2. 执行流程
1.  **扫描模型**：自动扫描 `models/spatial` 下所有注册模型。
2.  **批量生成**：对每个模型：
    - 实例化模型（使用默认小尺寸配置）。
    - 绘制架构图 (`_arch_v1.svg`)。
    - 绘制流程图 (`_flow_v1.svg`)。
    - 绘制性能图 (`_perf_v1.svg`)。
3.  **文件归档**：
    - 建立目录：`paper_package/figs/model_principles/<model_name>/`。
    - 生成说明：`caption.txt`（包含 LaTeX 格式的图题和详细说明）。

## 3. 技术规范对齐
- **格式**：SVG (矢量图，支持无限缩放)。
- **字体**：优先使用 `DejaVu Serif` (类 LaTeX 字体)。
- **分辨率**：矢量图天然满足 300dpi+ 要求。
- **配色**：使用 "SciencePlots" 风格或自定义学术配色板。

## 4. 预期产出
运行脚本后，您将获得如下结构的目录：
```text
paper_package/figs/model_principles/
├── UNet/
│   ├── unet_arch_v1.svg      (架构图)
│   ├── unet_flow_v1.svg      (流程图)
│   ├── unet_perf_v1.svg      (性能示意图)
│   └── caption.txt           (图注说明)
├── FNO2d/
│   ├── ...
...
```
此计划将一次性为您生成所有 30+ 个模型的标准配图，极大节省手工绘图时间。
