## 详细实施步骤 (Implementation Steps)

### Step 1: 编写数据绘图脚本 (plot_crop_capability.py)
- **目标**：使用 Python (`matplotlib`/`seaborn`) 绘制满足 IEEE Transactions 标准的曲线图。
- **具体要求**：
  - **横轴 (X-axis)**：观测面积占比 `Area Pct (%)`。由于数据从 76.56% 跨度到 0.01%，推荐采用**对数坐标轴 (Log-scale)** 或者**反向坐标系**，让极小面积区域（10%以下）有足够的展示空间，更好地体现“重建极限”。
  - **纵轴 (Y-axis)**：相对误差 `Rel-L2`。
  - **曲线标注 (Lines)**：
    - `UNet` (实线，带 Marker，显示出相对平滑的降级)
    - `EDSR` (虚线，带 Marker，在低观测区略逊于 UNet)
    - `PartialConvUNet` (点划线，带 Marker，恒定在 1.0 附近展示其完全失效)
  - **视觉辅助线**：在 `Rel-L2 = 1.0` 处绘制一条红色的虚线（水平线），代表“完全失效/退化为平凡解的理论极限（Random Guess / Trivial Solution）”。
  - **格式**：分辨率 ≥ 600 dpi，字号 ≥ 8 pt，保证打印清晰。
- **输出路径**：`thesis_paper/figures/crop_limit/crop_capability_curve.png` (及 `.pdf`, `.svg`)。
