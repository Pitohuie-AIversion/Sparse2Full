
# 优化标签排版与防重叠计划

## 核心目标
解决神经网络结构图中标签文字（caption）相互重叠的问题。不仅通过增加空间，还通过强制换行（`\\`）和调整标签位置来优化视觉效果。

## 具体实施步骤

### 1. 标签换行优化
检查所有生成器函数中的 `caption` 字段，对较长的标签或容易重叠的连续标签进行换行处理。
-   **SegFormer / SwinT**: `PatchEmbed` -> `Patch\\Embed`。
-   **FNO2d**: `Spectral Conv` -> `Spectral\\Conv`。
-   **通用**: `Stage 1` -> `Stage\\1`，`ResBlock 1` -> `ResBlock\\1`。

### 2. 空间微调
-   在密集排列的模块（如 SwinT 的 Stage 1 内部 `LN-Attn-LN-MLP`）中，进一步微调水平间距，确保文字有足够空间。
-   对于特别拥挤的区域，尝试交替标签位置（虽然 PlotNeuralNet 主要支持底部 caption，但可以通过调整 `zlabel` 或手动添加 `\node` 来辅助，目前优先用换行和间距解决）。

### 3. 代码修改清单
修改 `thesis_paper/figures_nn/export_and_gen_tikz.py`：
-   **gen_tikz_edsr**: `ResBlock 1` -> `ResBlock\\1`。
-   **gen_tikz_unet**: `Encoder 1` -> `Enc\\1`, `Decoder 1` -> `Dec\\1` 等。
-   **gen_tikz_segformer**: `Stage 1` -> `Stage\\1` 等。
-   **gen_tikz_swint**: `Stage 1` -> `Stage\\1` 等。
-   **gen_tikz_fno2d**: `Projection` -> `Proj.` (缩写) 或 `Projec-\\tion`。

### 4. 执行与验证
-   运行批处理脚本生成 PDF。
-   确认生成的 LaTeX 代码中双反斜杠 `\\\\` 正确转义（在 Python f-string 中需要 `\\\\` 才能输出 LaTeX 的 `\\`）。
