# PDEBench 2D Diffusion-Reaction 数据格式分析报告

## 文件基本信息

- **文件路径**: `data/DR2D/2D_diff-react_NA_NA.h5`
- **文件大小**: 12.63 GB
- **文件格式**: HDF5

## 数据集结构

### 顶级结构
- **总样本数**: 1000个独立的仿真样本
- **样本编号**: '0000' 到'0999' (4位数字字符串)

### 每个样本的结构
每个样本包含两个主要部分：

#### 1. 数据部分 (`data`)
- **形状**: `(101, 128, 128, 2)`
- **数据类型**: `float32`
- **维度含义**:
  - 第1维 (101): 时间步数
  - 第2维 (128): 空间网格高度
  - 第3维 (128): 空间网格宽度  
  - 第4维 (2): 物理量通道数

#### 2. 网格信息 (`grid`)
包含3个子数据集：
- **`t`**: 时间坐标 `(101,)` - 范围 [0.0, 5.0]
- **`x`**: x空间坐标 `(128,)` - 范围 [-0.9941, 0.9902]
- **`y`**: y空间坐标 `(128,)` - 范围 [-0.9941, 0.9902]

## 数据格式总结

这是一个典型的**时空序列数据集**，适用于：

1. **时间序列预测**: 给定前几个时间步，预测后续时间步
2. **超分辨率重建**: 从低分辨率恢复高分辨率
3. **稀疏重建**: 从部分观测恢复完整场

### 数据访问模式
```python
import h5py

with h5py.File(file_path, 'r') as f:
    # 访问第i个样本的数据
    sample_data = f[f'{i:04d}']['data'][...]  # shape: (101, 128, 128, 2)
    
    # 访问时间和空间网格
    t_grid = f[f'{i:04d}']['grid']['t'][...]  # shape: (101,)
    x_grid = f[f'{i:04d}']['grid']['x'][...]  # shape: (128,)
    y_grid = f[f'{i:04d}']['grid']['y'][...]  # shape: (128,)
```

### 适用任务
- **Super-Resolution (SR)**: 从低分辨率 (如64×64) 重建到高分辨率 (128×128)
- **Crop Reconstruction**: 从部分区域重建完整场
- **Temporal Prediction**: 时间序列预测
- **Multi-Physics Modeling**: 双通道物理量建模
