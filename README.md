# Real Data AR Training Library

This library provides tools and modules for training autoregressive models on real diffusion-reaction data.

## Installation

```bash
pip install -e .
```

## Structure

- `real_data_ar.config`: Configuration management.
- `real_data_ar.data`: Dataset and DataModule logic.
- `real_data_ar.models`: Model wrappers and factories.
- `real_data_ar.training`: Training logic and phases.
- `real_data_ar.utils`: Logging, device management, and helpers.

## Usage

See the `examples/` directory (to be added) or the `tools/` scripts for usage examples.
